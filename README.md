# BioNature India

> Sustainable Biological Inputs & Crop Solutions for Healthier Harvests across India.

BioNature India develops eco-friendly biological fertilizers, botanical crop protection, micronutrients, and bio-stimulants designed to restore soil vitality and maximize agricultural yield sustainably.

---

## 🚀 Features

- **Modern Responsive Web Application**: Built with React 19, Vite, and TailwindCSS.
- **Interactive UI & 3D Elements**: Smooth animations powered by Framer Motion, Three.js / React Three Fiber, and Radix UI primitives.
- **Product Catalog & Crop Solutions**: Comprehensive guides for biological fertilizers, pest management, and soil health.
- **Admin Dashboard & Inquiries**: Backend integration for managing dealer inquiries and customer requests.
- **WhatsApp & Contact Integration**: Direct communication channels for farmers and distributors.

---

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `pnpm`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Surya21-art/bionature.git
   cd bionature
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   pnpm install
   ```

3. Configure environment variables:
   Copy `.env.example` to `.env` and fill in any required credentials:
   ```bash
   cp .env.example .env
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:3000` (or `http://localhost:5173`).

---

## 📜 Available Scripts

- `npm run dev` - Runs both Vite dev server and Node backend concurrently
- `npm run dev:client` - Runs Vite frontend development server
- `npm run server` - Starts the Express backend server
- `npm run build` - Builds production bundle
- `npm run preview` - Previews production build locally
